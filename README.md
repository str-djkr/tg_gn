# Telegram Bot для карток лояльності

Цей бот видає користувачам унікальні коди з бази даних та дозволяє адміністраторам керувати кодами.  
Розроблений з використанням **Django** (для моделі даних) та **Aiogram** (для Telegram API).

---

## ⚙️ Можливості

- 🎯 Отримання унікального коду (користувачем).
- ⏳ Обмеження часу між запитами (20 секунд).
- 📦 Зберігання та видача кодів з бази даних (`RandomCode`).
- 📊 Перегляд кількості доступних кодів (адмін).
- ➕ Генерація нових кодів у заданому діапазоні (адмін).
- ℹ️ Інформаційне меню для користувачів та адміністраторів.

---

## 📂 Структура

- `bd/` — Django-додаток із моделями (`RandomCode`, `User`).
- `bd_random_code/models.py` — модель для збереження кодів.
- `config.py` — файл із токеном бота (`DataTg.telegram_token`).
- `bot.py` (або `main.py`) — логіка роботи Telegram-бота.
